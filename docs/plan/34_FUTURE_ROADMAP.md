# 34 — FUTURE ROADMAP

## v0.1 — After MVP

- Multiple agent models (not just coding; research + security).
- Full PRD → architecture workflow with human gates.
- Knowledge base seed (templates, playbooks).
- Organization memory basics.
- Project templates (reusable scaffolds for common app types).

---

## v0.5 — Robustness & Scale

- Task concurrency limits per project.
- Workflow recovery on crash (idempotent step replay).
- Formal test coverage tracking + quality gates.
- SAST + dependency audit tools integrated.
- Cost optimization (model routing tuning from historical data).
- Audit log completeness validation.

---

## v1.0 — Production Ready

- Multiple concurrent projects (org portfolio).
- Full security suite (SAST, DAST, dependency audit, secret scan).
- Performance testing agent + NFR verification.
- Multi-environment deployment (staging + prod).
- Monitoring agent + alerting on deployed apps.
- Frontend dashboard (Next.js) for human oversight.
- Deployment approval workflow.
- Retrospective learning (lessons → org memory).
- OIDC auth; multi-user support.

## v2.0 — Enterprise / SaaS

- Multi-tenant organizations.
- Marketplace for agent definitions, templates, playbooks.
- Plugin system for custom tools.
- Budget-based billing per project.
- Advanced autonomy (L4/L5).
- Continuous improvement: auto-tuning of prompts based on run metrics.

## v3.0 — Advanced Autonomy

- Cross-project knowledge transfer.
- Parallel projects sharing infrastructure.
- Autonomous research → specification → deployment with minimal gates.
- Agent self-assessment and skill evolution (within guardrails).
- Human acts purely as board oversight; system operates near-human-level.
